# Aqua

Three.js + TypeScript로 만든 픽셀 아쿠아리움이다. 480×270 게임 해상도를 창을 빈틈없이 덮게 확대하고(넘치는 쪽은 잘라 냄, `I`로 정수배), 마지막 수중 후처리가 모든 빛·번짐까지 같은 픽셀 격자로 다시 모은다. 같은 바다 장면 위에 타이틀과 `PRESS ANY KEY`가 뜨고, 아무 키나 클릭으로 들어간다.

## 실행

```bash
pnpm install
pnpm dev          # 개발 서버
pnpm build        # 타입 검사 + 배포 빌드(dist/)
```

| 입력 | 동작 |
|---|---|
| 생물에 마우스 올리기 | 연노랑 테두리와 이름이 뜨고, 그 생물이 조금 천천히 헤엄친다 |
| 기포에 마우스 스치기 | 기포가 작은 고리를 남기고 톡 터진다 |
| 생물을 왼쪽 클릭 | 그 종이 좋아하는 먹이(가루 먹이·물고기 과자·해초 잎·가라앉는 알갱이·반짝 플랑크톤)를 입 앞에 준다. 받아 먹으면 하트가 뜬다 |
| 빈 곳을 왼쪽 클릭 | 기본 가루 먹이를 뿌린다 |
| 생물을 오른쪽 클릭 | 교감: 복어는 부풀고, 게는 집게를 들고, 무리는 하트 대형을 만드는 등 종마다 다른 반응(37가지) |
| 빈 곳을 오른쪽 클릭 | 유리 두드리기(그 자리에서 화면이 둥글게 일렁이고 근처 물고기가 흩어짐) |
| `L` | 밤 손전등 |
| `B` | 배경 컨셉 바꾸기(소품 배치도 새로 흩음) |
| `Tab` / `←` `→` | 목격 도감 열기·쪽 넘기기 |
| `E` | 아무 사건 바로 일으키기 |
| `P` | 119색 게임 팔레트로 모으기 켜기/끄기(기본 꺼짐) |
| `C` | CRT 스캔라인 켜기/끄기(기본 꺼짐) |
| `F` / `F11` | 전체 화면 |
| `I` | 정수배 확대 켜기/끄기(기본 꺼짐) |

실행할 때마다 배경 컨셉 5가지(산호초·켈프 숲·난파선·해저 유적·빙하 바다) 가운데 하나가 무작위로 나오고, 산호·해초·조개 소품도 그 컨셉에 어울리는 것들로 매번 다른 자리에 놓인다(가운데는 비워 둔다). 조개는 앞을 보고 천천히 입을 벌렸다 닫으며, 생물이 지나가거나 유리를 두드리면 닫는다. 처음 등장하는 생물도 실행마다 다르다.

하루는 240초(10초가 한 시간, 0초가 정오)이고 황혼·새벽에는 수면 쪽이 노을빛으로 물든다. 생물마다 실제 습성에 맞춘 활동 시간이 있어 시간이 되면 나오고 끝나면 들어간다(헤엄치는 생물은 화면 밖으로, 바닥 생물은 모래 속으로). 밤에는 빛나는 생물이 먼저 나오고, 강하게 빛나는 생물은 3~4겹 둥근 빛 고리를 두른다. 고래·상어·거북 같은 큰 생물은 사건 연출이 아니면 중간에 돌아서지 않는다.

소소한 볼거리도 있다: 은빛 무리 반짝임, 수면 반사와 달(위상이 바뀜), 생물이 헤치고 지나가는 해초, 발광 생물의 바닥 빛 웅덩이, 모래 발자국, 손전등에 떠오르는 바다눈, 구름 그림자, 희귀 색 변이(황금·알비노·흑색)와 방문자 단골 개체, 새벽에 잠들며 꿈꾸는 문어, 포인터로 스치면 터지는 기포.

바다에는 해양 생물 231종(도감 217종 + 사건 때만 오는 고래·고래상어 등 방문자 14종)이 산다. 이벤트 감독이 22~40초마다 사건 하나를 골라 일으킨다: 상어의 순찰, 초롱아귀의 등불, 해파리 대발생, 산호 산란, 청소 정거장, 간식 바구니, 잠수부, 고래가 지나간다(전설) 등 39종. 모든 생물은 적어도 한 사건에 반응하고, **사건이나 교감에서 생물끼리 잡아먹는 일은 없다.** 목록은 [doc/events.md](doc/events.md), 교감·먹이·활동 시간은 [doc/interaction.md](doc/interaction.md).

## 배포

`main`에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 테스트와 빌드를 거쳐 GitHub Pages에 올린다: https://clazyzombie.github.io/aqua/ . 저장소 Settings > Pages의 Source는 "GitHub Actions"여야 한다.

PWA로 설치할 수 있다. 크롬·엣지는 주소창의 설치 버튼, 안드로이드는 "홈 화면에 추가", iOS 사파리는 공유 > "홈 화면에 추가"를 쓴다. 전체 화면·가로로 열리고, 서비스 워커(`public/sw.js`)가 한 번 받은 파일을 저장해 두어 다음부터는 오프라인에서도 열린다. 아이콘은 `scripts/build_icons.py`가 굽는다(`pnpm assets`에 포함). 스모크 테스트가 Chromium의 설치 조건(`Page.getInstallabilityErrors`)과 서비스 워커를 확인한다.

## 에셋 빌드

```bash
pnpm assets   # art/ 원본 → public/assets 시트(색·노멀·발광·교감 자세)·배경 컨셉 층·소품 + src/data 목록 JSON + 팔레트
pnpm qc       # 에셋 계약 검사
```

원본 그림은 `art/`에 있고 생성 프롬프트는 [art/PROMPTS.md](art/PROMPTS.md), 종 목록·그룹은 `scripts/species_table.py`에 있다. 교감 자세 그림은 `art/species/<id>-pose.png`로 두면 원본과 같은 배율로 구워진다.

## 검증

```bash
pnpm test        # vitest: 시뮬레이션, 모든 종의 먹이·교감, 활동 시간, 큰 생물 직진, 기준 기록
pnpm e2e         # headless Chromium 캡처(output/capture) 후 화면·상태 검사
pnpm smoke       # 실제 루프·키·마우스(격자 호버·좌우 클릭)·창 크기 스모크
pnpm reference   # 동작을 일부러 바꾼 뒤 tests/fixtures/reference-seed7.json 기준 기록 다시 만들기
```

E2E는 타이틀·낮·고래가 지나는 황혼·밤·새벽·번개·먹이, 호버 테두리와 이름, 교감(게 집게·복어·진주·돌고래 점프·무리 하트), 건넨 먹이의 하트, 밤 빛 고리, 강제로 일으킨 사건을 캡처해 확인한다. 발광 종 전부(평상시·교감)와 밤 사건은 빛이 보이면서도 하얗게 타지 않는지 전수 검사한다. 2×2 픽셀 격자, 진행 방향과 바라보는 방향의 일치, 창 크기와 관계없이 검은 여백 없음도 본다.

캡처 쿼리(`?capture=1&...`): `seconds`, `seed`(기본 7, 창 모드는 매번 무작위), `scene`(배경 컨셉, 캡처 기본 reef), `layout`(소품 배치 시드, 기본은 seed), `started`, `size=WxH`, `integer`, `pointer=x,y`, `feedAt`, `tapAt`, `event`·`eventAt`, `cast`(종 id)·`castAt`(포인터 자리에 부르기), `reactAt`(교감), `treatAt`(그 생물 먹이), `variant`(0~3, 부른 생물의 색 변이), `individual`(0~2, 단골 개체), `hover=0`(호버 끄기), `flashlight`, `dex`.
