# Aqua

Three.js + TypeScript로 만든 픽셀 아쿠아리움이다. 화면은 휴대폰 가로 화면(아이폰 17, 약 2.17:1)에 맞춘 588×270 월드를 빈틈없이 덮게 확대하고, 그보다 짧은 화면(16:9 데스크톱 등)은 양옆부터 잘라 가운데 480×270 무대를 보여 준다(`I`로 정수배). 마지막 수중 후처리가 모든 빛·번짐까지 같은 픽셀 격자로 다시 모은다. 같은 바다 장면 위에 타이틀과 `PRESS ANY KEY`(터치 화면은 `TAP TO START`)가 뜨고, 아무 키나 클릭·탭으로 들어간다.

## 실행

```bash
pnpm install
pnpm dev          # 개발 서버
pnpm build        # 타입 검사 + 배포 빌드(dist/)
```

| 입력 | 동작 |
|---|---|
| 생물에 마우스 올리기 | 연노랑 테두리와 이름이 뜨고, 그 생물이 조금 천천히 헤엄친다 |
| 기포에 마우스 스치기 | 기포가 작은 고리를 남기고 톡 터진다 |
| 생물을 왼쪽 클릭 | 그 종이 좋아하는 먹이(가루 먹이·물고기 과자·해초 잎·가라앉는 알갱이·반짝 플랑크톤)를 입 앞에 준다. 받아 먹으면 하트가 뜬다 |
| 빈 곳을 왼쪽 클릭 | 기본 가루 먹이를 뿌린다 |
| 생물을 오른쪽 클릭 | 교감: 복어는 부풀고, 게는 집게를 들고, 무리는 하트 대형을 만드는 등 종마다 다른 반응(39가지) |
| 빈 곳을 오른쪽 클릭 | 유리 두드리기(그 자리에서 화면이 둥글게 일렁이고 근처 물고기가 흩어짐) |
| 쓰레기를 왼쪽 클릭 | 치운다(반짝이며 사라짐). 쓰레기에도 호버하면 테두리와 이름이 뜬다 |
| 아래 가운데 낚싯대 버튼 / `G` | 낚시 모드 켜기/끄기. 낚시 중에는 왼쪽 버튼(또는 `Space`)을 누르고 떼서 던지고·채고·감는다 |
| `M` | 소리 켜기/끄기(다음 실행에도 기억) |
| `L` | 밤 손전등 |
| `B` | 배경 컨셉 바꾸기(소품 배치도 새로 흩음) |
| `Tab` / `←` `→` | 목격 도감 열기·쪽 넘기기 |
| `E` | 아무 사건 바로 일으키기 |
| `P` | 119색 게임 팔레트로 모으기 켜기/끄기(기본 꺼짐) |
| `C` | CRT 스캔라인 켜기/끄기(기본 꺼짐) |
| `F` / `F11` | 전체 화면 |
| `I` | 정수배 확대 켜기/끄기(기본 꺼짐) |

휴대폰·태블릿(터치)에서는 이렇게 쓴다.

| 터치 | 동작 |
|---|---|
| 탭 | 마우스 왼쪽 클릭과 같다(생물이면 그 종 먹이, 빈 곳이면 가루 먹이, 쓰레기면 치우기). 탭한 생물은 테두리와 이름이 잠깐 뜬다 |
| 길게 누르기(0.45초) | 마우스 오른쪽 클릭과 같다(생물이면 교감, 빈 곳이면 유리 두드리기) |
| 끌기 | 손가락이 지나간 기포가 톡 터진다 |
| 오른쪽 위 ☰ | 도감·손전등·소리·배경 바꾸기·사건 일으키기·전체 화면(지원하는 브라우저만) |
| 도감 양옆·가운데 탭 | 쪽 넘기기·닫기 |
| 아래 가운데 낚싯대 버튼 | 낚시 모드(누르고 떼기·탭만으로 던지고 채고 감는다) |

가로 화면에 맞춘 게임이라 세로로 들면 가로로 돌려 달라는 안내가 뜬다. 노치·둥근 모서리까지 화면을 쓰고(`viewport-fit=cover`), 두 손가락 확대·스크롤·길게 눌러 뜨는 메뉴는 막는다. 아이폰 사파리에는 전체 화면 기능이 없으므로 "홈 화면에 추가"(PWA)로 열면 주소창 없이 꽉 찬다.

실행할 때마다 배경 컨셉 5가지(산호초·켈프 숲·난파선·해저 유적·빙하 바다) 가운데 하나가 무작위로 나오고, 산호·해초·조개 소품도 그 컨셉에 어울리는 것들로 매번 다른 자리에 놓인다(가운데는 비워 둔다). 조개는 앞을 보고 천천히 입을 벌렸다 닫으며, 생물이 지나가거나 유리를 두드리면 닫는다. 처음 등장하는 생물도 실행마다 다르다.

하루는 240초(10초가 한 시간, 0초가 정오)이고 황혼·새벽에는 수면 쪽이 노을빛으로 물든다. 생물마다 실제 습성에 맞춘 활동 시간이 있어 시간이 되면 나오고 끝나면 들어간다(헤엄치는 생물은 화면 밖으로, 바닥 생물은 모래 속으로). 밤에는 빛나는 생물이 먼저 나오고, 강하게 빛나는 생물은 3~4겹 둥근 빛 고리를 두른다. 고래·상어·거북 같은 큰 생물은 사건 연출이 아니면 중간에 돌아서지 않는다.

소소한 볼거리도 있다: 은빛 무리 반짝임, 수면 반사와 달(위상이 바뀜), 생물이 헤치고 지나가는 해초, 발광 생물의 바닥 빛 웅덩이, 모래 발자국, 손전등에 떠오르는 바다눈, 구름 그림자, 희귀 색 변이(황금·알비노·흑색)와 방문자 단골 개체, 새벽에 잠들며 꿈꾸는 문어, 포인터로 스치면 터지는 기포.

바다에는 해양 생물 231종(도감 217종 + 사건 때만 오는 고래·고래상어·아델리펭귄 등 방문자 14종)이 살고, 사건 때 아쿠아다이버·해녀·인어공주가 찾아온다. 이벤트 감독이 22~40초마다 사건 하나를 골라 일으킨다: 상어의 순찰, 해파리 대발생, 만타 캠프파이어, 해마 아빠의 출산, 소라게 집 바꾸기, 해녀의 물질, 인어공주의 노래(전설), 배경 컨셉마다 다른 장면(켈프 숲 햇살 커튼, 난파선 속 금화, 룬이 빛나는 밤, 얼음 너머 오로라) 등 70종. 해녀와 다이버는 먹이를 받으면 먹지 않고 둘레 생물에게 나눠 준다. 모든 생물은 적어도 한 사건에 반응하고, **사건이나 교감에서 생물끼리 잡아먹는 일은 없다.** 목록은 [doc/events.md](doc/events.md), 교감·먹이·활동 시간은 [doc/interaction.md](doc/interaction.md).

## 쓰레기 줍기

게임을 시작하면 10~20초마다 캔·페트병·비닐봉지·장화·타이어·유리병·마스크·폐그물 가운데 하나가 수면에서 나풀거리며 가라앉아 바닥에 쌓인다. 10개부터 물이 갈색 섞인 초록으로 탁해지고 빛줄기가 흐려지며, 쌓일수록 수초(흔들리는 해초·켈프·말미잘)가 하나씩 시들어 사라지고 산호가 바랜다. 30개가 되면 새 생물이 오지 않는다(10개를 넘으면 쌓인 만큼 덜 온다). 쓰레기를 하나하나 눌러 치우면 물빛·수초·생물이 서서히 돌아온다.

## 낚시

아래 가운데 낚싯대 버튼(`G`)으로 낚시 모드에 들어간다. 잡은 물고기는 수면에서 잠깐 보여 준 뒤 놓아 준다(잡아먹지 않는다). 잡은 종은 도감에 ◎로 남는다.

1. **던지기**: 물속 겨눌 곳을 누르고 있으면 힘 게이지가 오르내린다. 초록(완벽)·노랑(좋음) 칸에서 떼면 겨눈 곳 가까이, 벗어나면 멀리·짧게 떨어진다. 가라앉는 미끼는 탭하면 그 깊이에 멈춘다.
2. **입질**: 근처 물고기가 식성·경계심대로 다가와 미끼를 몇 번 툭툭 건드리고(찌가 살짝 까딱) 문다(찌가 푹 잠기고 물보라). 문 순간에 탭해야 걸린다. 너무 일찍 채면 놀라 달아나고, 늦으면 미끼만 떼인다. 초식·플랑크톤 먹는 종은 잘 오지 않고 큰 물고기는 경계심이 많아, 원하는 물고기를 골라 물리기는 쉽지 않다. 길게 누르면 미끼를 걷는다.
3. **싸움**: 누르고 있으면 감고, 떼면 풀어 준다. 장력 게이지가 빨간 칸에 오래 머물면 줄이 끊어지고, 너무 느슨하면 바늘이 빠지며, 줄이 다 풀려도 끊어진다. 물고기는 가끔 "당긴다!" 하고 치고 나가니 그때는 풀어 주고, 쉬거나 달려들 때 감는다. 체력(파란 띠)이 떨어질수록 힘이 약해진다.
4. **난이도**: 종마다 크기·무리·식성으로 별 1~5개(힘·체력·돌진 빈도·입질 시간·경계심)가 정해진다. 흰동가리는 계속 감아도 잡히지만, 참치·상어는 장력을 보며 풀고 감아야 20~45초 만에 잡힌다. 복어는 걸리면 부풀고, 오징어는 치고 나갈 때 먹물을 뿜는다.

## 소리

첫 키·클릭·터치에서 소리가 켜진다(브라우저가 그 전에는 소리를 막는다). `M`으로 끄고 켠다.

- 배경 음악: 낮 곡 4개와 밤 곡 2개를 섞어 튼다. 시간대가 바뀌면 5초에 걸쳐 엇갈려 바꾸고, 낮·밤 목록마다 멈춘 자리를 기억했다가 다시 그 시간대가 오면 이어서 튼다. 짧은 루프 곡은 2분 반쯤 되풀이한 뒤 다음 곡으로 넘어간다.
- 물속 소리: 먹먹한 물속 앰비언스를 늘 깔고, 수면 찰랑임은 낮과 폭풍에 조금 커진다. 먹이를 주거나 유리를 두드리거나 기포를 터뜨리거나 다이버·흰고래가 도넛 고리를 불면 그 자리 쪽(좌우)에서 보글 소리가 나고, 가끔 멀리서 저절로 기포 소리가 오른다.
- 창을 숨기면 소리를 멈춘다. 코드는 `src/audio.ts`다.

음원은 `pnpm audio`(`scripts/build_audio.py`)가 출처에서 받아(`.cache/audio/`) 음량을 맞추고 mp3로 구워 `public/assets/audio/`에 둔다(9개, 약 12MB). 출처와 라이선스는 [public/assets/audio/CREDITS.txt](public/assets/audio/CREDITS.txt)에 있다. 밤 곡 둘은 CC BY 3.0이라 타이틀 화면 아래에 저작자를 적었고, 나머지는 CC0다.

## 배포

`main`에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 테스트와 빌드를 거쳐 GitHub Pages에 올린다: https://clazyzombie.github.io/aqua/ . 저장소 Settings > Pages의 Source는 "GitHub Actions"여야 한다.

PWA로 설치할 수 있다. 크롬·엣지는 주소창의 설치 버튼, 안드로이드는 "홈 화면에 추가", iOS 사파리는 공유 > "홈 화면에 추가"를 쓴다. 전체 화면·가로로 열리고, 서비스 워커(`public/sw.js`)가 한 번 받은 파일을 저장해 두어 다음부터는 오프라인에서도 열린다. 아이콘은 `scripts/build_icons.py`가 굽는다(`pnpm assets`에 포함). 스모크 테스트가 Chromium의 설치 조건(`Page.getInstallabilityErrors`)과 서비스 워커를 확인한다.

## 에셋 빌드

```bash
pnpm assets   # art/ 원본 → public/assets 시트(색·노멀·발광·교감 자세)·배경 컨셉 층·소품 + src/data 목록 JSON + 팔레트
pnpm audio    # 음원 출처에서 받아 음량 맞춰 public/assets/audio/*.mp3로 굽기(ffmpeg 필요)
pnpm qc       # 에셋 계약 검사
```

원본 그림은 `art/`에 있고 생성 프롬프트는 [art/PROMPTS.md](art/PROMPTS.md), 종 목록·그룹은 `scripts/species_table.py`에 있다. 교감 자세 그림은 `art/species/<id>-pose.png`로 두면 원본과 같은 배율로 구워진다.

## 검증

```bash
pnpm test        # vitest: 시뮬레이션, 모든 종의 먹이·교감, 활동 시간, 큰 생물 직진, 기준 기록
pnpm e2e         # headless Chromium 캡처(output/capture) 후 화면·상태 검사
pnpm smoke       # 실제 루프·키·마우스(격자 호버·좌우 클릭)·창 크기·소리 스모크
pnpm reference   # 동작을 일부러 바꾼 뒤 tests/fixtures/reference-seed7.json 기준 기록 다시 만들기
```

E2E는 타이틀·낮·고래가 지나는 황혼·밤·새벽·번개·먹이, 호버 테두리와 이름, 교감(게 집게·복어·진주·돌고래 점프·무리 하트), 건넨 먹이의 하트, 밤 빛 고리, 강제로 일으킨 사건을 캡처해 확인한다. 발광 종 전부(평상시·교감)와 밤 사건은 빛이 보이면서도 하얗게 타지 않는지 전수 검사한다. 2×2 픽셀 격자, 진행 방향과 바라보는 방향의 일치, 창 크기와 관계없이 검은 여백 없음도 본다. 사건 2부 31종은 찍은 순간에도 사건이 이어지는지, 무대 장치와 출연진이 남아 있는지, 오로라·불꽃·흰동가리 알이 보이는지 본다. 스모크는 PWA 설치 조건과 함께 첫 입력 뒤 소리가 실제로 켜지고 `M`으로 꺼졌다 켜지는지 본다. 휴대폰 에뮬레이션(874×402, 3배, 터치)으로 탭 시작·탭 먹이·길게 눌러 유리 두드리기·메뉴로 도감과 손전등·도감 탭 넘기기·세로 안내도 확인한다. e2e는 휴대폰 비율 캡처(`size-phone*`)에서 픽셀 격자와 양옆 여백 그림을 본다.

캡처 쿼리(`?capture=1&...`, `size=1176x540`이면 휴대폰 가로 화면 비율): `seconds`, `seed`(기본 7, 창 모드는 매번 무작위), `scene`(배경 컨셉, 캡처 기본 reef), `layout`(소품 배치 시드, 기본은 seed), `started`, `size=WxH`, `integer`, `pointer=x,y`, `feedAt`, `tapAt`, `event`·`eventAt`, `cast`(종 id)·`castAt`(포인터 자리에 부르기), `reactAt`(교감), `treatAt`(그 생물 먹이), `variant`(0~3, 부른 생물의 색 변이), `individual`(0~2, 단골 개체), `depth=0`(부른 생물을 먼 층에), `hover=0`(호버 끄기), `flashlight`, `dex`.
